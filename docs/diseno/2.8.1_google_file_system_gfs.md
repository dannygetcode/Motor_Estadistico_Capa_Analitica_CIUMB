### 2.8.1 Google File System (GFS)

Ghemawat et al. (2003) presentaron un sistema de archivos distribuido para aplicaciones con uso intensivo de datos, que corre sobre hardware económico y trata las fallas de los componentes como algo normal y no excepcional. Divide los archivos en bloques de 64 MB, los replica en varios servidores y centraliza los metadatos en un nodo maestro. HDFS, el sistema de archivos de Hadoop, sigue ese diseño.
