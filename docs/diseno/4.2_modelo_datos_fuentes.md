## 4.2 Modelo de Datos de las Fuentes

El proyecto tiene dos fuentes de datos. La fuente 1 es la base de datos transaccional del sistema del CIUMB, que contiene los siete módulos. La fuente 2 es el esquema rpt_ del servicio de informes, que el área analítica crea y que guarda la capa semántica, las plantillas base, las especificaciones y la trazabilidad de cada informe; es fuente porque de él salen los informes de uso y de calidad del servicio.

Aclaración sobre el origen del modelo. A la fecha de entrega de este documento, el equipo que orquesta e integra el sistema del CIUMB no ha entregado al área analítica el modelo entidad-relación ni el diccionario de datos de la base de datos. Tampoco está confirmado el motor. El documento de requerimientos menciona MySQL, pero en la reunión de inicio se aclaró que el sistema no usa ese motor. Por esa razón, el modelo de la fuente 1 que se presenta aquí es un modelo lógico inferido de las funcionalidades y los indicadores descritos en los requerimientos, como lo prevé su sección 1.4 (Centro de Investigaciones UMB, 2026). Los nombres de tablas y campos son provisionales y se confirmarán en el Sprint 1. El diseño del datawarehouse no depende de esos nombres, porque las vistas de extracción funcionan como capa de traducción. Si un campo real se llama distinto, solo cambia la vista.
