### 2.5.1 Analítica de datos (analytics)

Es el uso extensivo de datos, análisis estadístico y cuantitativo y modelos explicativos y predictivos para orientar decisiones (Davenport y Harris, 2007). Es el área en que se ubica esta práctica. Datos estructurados de una organización, procesados con estadística y aprendizaje automático, para producir indicadores.
