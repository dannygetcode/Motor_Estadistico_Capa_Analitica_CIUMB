## 2.8 Herramientas teóricas que dan soporte a las tecnologías Big Data

Tres artículos de Google publicados entre 2003 y 2008 describieron el sistema de archivos, el modelo de programación y el almacén de datos que inspiraron a Hadoop, HDFS y HBase, y con ellos buena parte del ecosistema de Big Data de código abierto.
