### 2.2.2 Datos semiestructurados

No tienen un esquema rígido, pero llevan etiquetas o marcas que separan sus elementos, como XML o JSON. Abiteboul (1997) los describe como datos cuyo esquema está implícito en los propios datos y puede variar de un registro a otro. En este proyecto aparecen en tres lugares. La especificación de informe que se deriva de cada prompt, el paquete del contrato de datos que viaja a la IA y la respuesta del modelo de lenguaje, que debe llegar como JSON validable. Para controlarlos se usa JSON Schema, de modo que una especificación, un paquete o una respuesta con campos faltantes se rechaza antes de procesarse.
