## 2.4 Big Data Analytics

Big Data Analytics es el proceso de examinar grandes conjuntos de datos para descubrir patrones, correlaciones y tendencias que apoyen la decisión. Hu et al. (2014) lo describen como una cadena de valor de cuatro fases. Generación, adquisición, almacenamiento y análisis. La tabla de contenido de esta práctica usa cuatro fases equivalentes. Adquisición, organización, análisis y decisión. Cada una corresponde a un bloque del diseño del capítulo 4.
