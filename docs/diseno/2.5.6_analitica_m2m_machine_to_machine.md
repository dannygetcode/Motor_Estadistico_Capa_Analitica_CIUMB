### 2.5.6 Analítica de M2M (machine to machine)

Analiza los datos que intercambian dispositivos sin intervención humana, típicamente sensores conectados en el internet de las cosas. Wu et al. (2011) describen esta comunicación como el paso del internet móvil a un internet embebido en objetos. No aplica al CIUMB en términos de sensores; la interacción más cercana es la del servicio de informes con las API de los proveedores de IA, que es una comunicación entre sistemas, pero sin el componente de dispositivos físicos que define esta área. La Tabla 6 resume la relación de cada área con el proyecto.

**Tabla 6. Relación de las áreas de análisis de datos con el proyecto**

| Área | Relación con el proyecto | Grado |
|---|---|---|
| Analítica de datos | Núcleo del área analítica: indicadores, inferencia, pronóstico y segmentación | Alta |
| Analítica web | Actividad de acceso al sistema del CIUMB (INF-USR-02) | Baja |
| Analítica social | Marco conceptual; no hay datos de redes en la base del CIUMB | Conceptual |
| Analítica móvil | No aplica; solo diseño adaptable del panel | No aplica |
| Analítica de Big Data | Se adoptan sus principios, no su infraestructura distribuida | Media |
| Analítica M2M | No aplica; la integración entre sistemas es por API REST | No aplica |
